# 当前 Skill 的生产验收

适用范围：单人、本地、免费公开来源、Skill 驱动研究、中文 Excel/CSV 交付。代码与规则测试通过后可以开始受控试运行；真实批次与一次校准完成前，不宣称匹配准确率、联系方式归属准确率、可达性或八小时交付已经达标。

## 统一分母

- `quantity` 是最终可交付的独立企业数，默认 200；候选上限为目标三倍，默认 600。
- 合格企业必须符合目标客群；可交付企业还必须通过抑制、去重，并有至少一个具备字段级原文证据的公开商务邮箱、电话或实际联系表单。
- 邮箱、电话覆盖率以合格企业为分母。联系表单可以构成交付渠道，但不增加历史“邮箱或电话覆盖率”的分子。
- “有公开来源”“语法/MX 检查通过”和“实际可达”分别报告。不得用前两者替代送达或接通验证。
- 达到候选/时间上限且少于目标时交付实际数量和缺口。旧 BRD 中“200 家候选、160 家合格”的阶段标准不能替代本版本“200 家可交付企业”的完成目标。

## 发布前技术检查

1. 在隔离 PostgreSQL 中运行完整测试，无跳过；覆盖字段证据缺失、官网错绑、否定及客户行业语境、真实目录渠道、同域不同主体、抑制和导出。
2. 验证跨进程 429 冷却及重试时间、已知旧基线的增量升级、备份前损坏拒绝、恢复文件与数据库原始哈希一致，以及删除前回滚/删除后失败的恢复。
3. Windows 安装烟测、冻结代码的校验、升级及旧发布重新激活通过；发布快照不包含 `.env`、数据库或业务文件。导出记录实际代码发布标识、schema 和规则版本。
4. 升级业务库前保存数据库/文件备份。代码回退不自动降级数据库；旧发布必须支持当前 schema，或者切换到已验证的独立恢复库和对应文件目录。

## 真实批次与一次校准

使用已确认的首批客群：美国货代，免费公开来源，目标 200 家。保留真实目标，不将小批烟测的分母改为已产出数量。

保存来源/查询计划及每轮检查点，记录候选、合格、可交付、排除、未确认、失败、缺口，邮箱/电话覆盖率、去重、来源拒绝、工具调用和端到端非暂停时间。完成一批真实 200 家才可报告该批完成；一次成功不能证明 P95。

从产出中独立抽取 50 条做一次校准，记录目标客群匹配、企业—官网关联、联系方式归属和来源可追溯情况。参考原 BRD：客群匹配至少 85%，联系方式归属至少 90%，来源可追溯 100%；免费源邮箱/电话覆盖率各至少 40%、邮箱或电话覆盖率至少 70%。出现错绑或无原文联系方式时，先分析错误来源，再决定是否扩大使用范围。此次校准不是日常逐条人工审核要求。

200 家八小时为待实测目标；计时包含所有非暂停墙钟间隔。关闭聊天或机器异常不会自动暂停。缺少真实测试时，验收状态保持“未验证”，不可用程序测试结果填充业务指标。
