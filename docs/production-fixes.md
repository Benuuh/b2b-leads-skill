# 生产使用缺口修复记录

日期：2026-10-24。当前核心版本：2.0.1；schema：skill_v2_002；交付规则：b2b-delivery-2。

## 已修复

- 联系方式必须有逐字段、带时间和 URL 的字面原文观察；取消原始邮箱/电话字段自动生成证据及仅凭来源链接交付的回退。中文 Excel 的 Sources 表保留原文摘录。
- 官网归属根据明确企业—网址观察或官网主体与已知实际地址/城市确认。不同官网主体不能被正文中的客户提及覆盖；同域独立企业仍可凭明确主体证据保留。导出包含官网归属状态及依据。
- 行业判断读取实际观察文本，不把输入的 industry_text 当作来源证据。明确自身服务/有主体的行业分类才支持资格，否定、软件产品、客户行业、新闻和不明确语境转为未确认。
- 主机级请求间隔、请求租约、429 冷却持久化到 PostgreSQL；数字及 HTTP-date Retry-After 跨命令、跨批次生效。任务重试保留上游状态及等待时间，状态返回 next_retry_at。未经证实的原始渠道不能吞掉待重试错误。
- 已核验 robots 规则持久缓存最多一小时，长 crawl-delay 到期后新进程可继续抓取业务页面；过期缓存随调用清理。observed-2 区分已发送、发送前拒绝和发送状态未知，未知请求不填成零。
- 备份对照数据库原始哈希，恢复后复查最终文件；旧报告对照数据库中的原始 manifest。新报告记录独立哈希。
- 撤销和删除在原事务中写入持久待办，提交后执行文件删除；文件占用、断电或数据库提交失败后可重试，不会在事务回滚前先丢文件。
- 安装将 Skill/核心/迁移/依赖锁冻结为带摘要的发布快照。入口拒绝发布漂移、额外模块及字节码缓存、跨项目错绑和畸形清单；普通激活写入失败恢复旧文件。中途进程退出时校验失败，重新安装可恢复。
- 批次和导出记录实际发布标识；支持激活保留的旧代码发布。代码回退不隐式降级数据库。CI 增加 Windows/Linux 安装验证。
