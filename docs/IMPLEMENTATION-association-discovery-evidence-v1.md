# 协会目录与国家证据：实施基线

日期：2026-11-03。规格：[SPEC-association-discovery-evidence-v1](specs/SPEC-association-discovery-evidence-v1.md)。此文件记录实施进度，不构成发布或验收。

## 已完成

- `capabilities` 离线披露共享目录页统一计量、自动 JS 渲染、国家规则版本分派均不可用，以及当前使用旧版字面国家匹配。
- 工作区 Skill 增加全国和地方协会来源选择、来源台账、逐主体取证、失败分流和当前计量/渲染能力边界。证据合同补充国家角色、目录主体绑定和旧规则局限。这些是操作指引，不代表核心已实现来源台账或强制检查。
- `test_association_discovery_baseline.py` 以合成样本固定现有 policy-2 行为：`USA`、`U.S.` 不命中，`United States` 命中，小写代词 `us` 不命中，单独 `CA` 可被识别为加拿大；标记为总部字段的德国办公室观察被判定为总部通过。这些例子不代表任何实际批次的原因或人工真值验收。
- 本次运行离线基线、资格、配置及 PostgreSQL 重评测试共 33 项通过。测试数据库使用项目现有隔离 fixture，不以 SQLite 替代。

## 尚未实现或验收

- 尚未从实际批次建立脱敏样本、人工逐条真值或耗时基线；没有新旧规则固定样本对照（AC-08、AC-09）。
- 现有 `plan.rules_version` 是记录，不是运行时分派；预检、准入、补证、重评、处理及交付路径尚未按冻结规则隔离。新版国家规则、地址数据和角色语义尚未实现；不得将新编号写入发布清单或对旧批次重评套用新语义（AC-03、AC-04）。
- 尚无由核心统一预留、持久化和恢复的共享目录页预算；外部工具计数不是核心页面或物理请求计量。目录发现、来源台账及本次指引尚无 AC-01、AC-02、AC-06 所要求的自动化验收。无法准确计量时不得启用自动共享页面采集路径。
- JS 渲染未实现；无法保证浏览器子请求等效网络防护及统一预算，保持不可用。静态及各失败场景尚未按本规格完成完整安全验收（AC-05）。

- 当前修改标记为源码 Skill/核心 **2.3.1**，仅在工作区，未打包安装或发布；已安装的冻结 Skill 不会自动获得这些指引或能力声明。规则仍为 `b2b-policy-2`，schema 仍为 `skill_v2_002`；该版本号不表示规格验收完成。
