# Benchmark evidence

These files contain only the fixed synthetic cohort (`Bench Company`, `example.com`) and isolated `sca_bench_*` PostgreSQL measurements from 2026-11-07. Raw candidate snapshots from public customer research are not published in this sanitized repository; the historical aggregate measurement is described in `docs/IMPLEMENTATION-runtime-efficiency-v2.6.md`.

Wall-time runs do not enable `tracemalloc`; memory runs are marked separately.
